## 정책에 반영할 후보 문장

다음은 운영 배포 전 문안이다. 업체 회신과 구체적 국가 표가 준비되면 외부 서비스 절에 합친다.

> Cloudflare의 웹 요청 처리는 글로벌 edge 네트워크에서 이루어지며, 요청·보안 관련 메타데이터는 업체의 한국 개인정보보호법 안내에 따라 미국과 유럽의 데이터센터에서도 처리될 수 있습니다. R2 객체 저장과 사본·지원 접근의 위치는 웹 요청 처리와 별도로 확인합니다. 현재 두 버킷의 APAC 표시는 아시아·태평양 지역 표시이며 특정 국가로 저장·처리를 제한한다는 보장이 아닙니다.

위 문장은 미국·유럽이라는 범위를 투명하게 설명하는 보완안이며, 필요한 전체 이전 국가와 법적 근거를 확정한 표를 대신하지 않는다. 업체의 일반 개인정보처리방침에서 운영자 계정 정보에 적용하는 기간을 code-lily 회원 DB의 기간으로 복사하지 않는다.

## 확정 전에 채울 항목

각 국외 처리 경로에 대해 적용 근거, 이전 항목, 국가, 시기·방법, 수신 법인·연락처, 목적·보유 기준, 거부 절차·영향을 확인한다. 계약 이행에 필요한 국외 처리위탁·보관은 개인정보 보호법 제28조의8 제1항 제3호의 적용을 검토하되, 필요성·고지·보호조치를 충족했다고 미리 기재하지 않는다. EU SCC·CBPR·PRP 인증만으로 한국의 별도 이전 근거가 된다고 간주하지 않는다.

2026-11-05 Google 인증센터는 앱이 Testing이므로 인증이 필요하지 않다고 표시했다. 이는 Production 전환 후 브랜드 검증이 불필요하다는 판단이 아니다. 이번에는 게시·검증 제출·추가 법적 동의를 수행하지 않았다.

정책 확정의 미해결 사실은 [업체별 확인 요청 문안](업체-개인정보-확인요청.md) 3통으로 구체화했다. 운영자의 명시 승인 후 20:40:13~20:40:22 KST에 발송하고 보낸편지함의 수신자·제목·SENT를 대조했다. 운영자에게 계약 사실을 추정해 답하도록 요청하지 않고, 실제 공급자의 문서·회신으로 채운다. 수신·담당자 접수·사실 확인 회신은 아직 확인하지 않았다.

## 추가 운영 확인

공급자 통지 확인 중 Tunnel의 최소 업그레이드 안내도 확인했다. 실제 블로그 컨테이너의 `cloudflared --version`은 2026.10.7로, 안내의 Linux 최소 버전 2026.10.2를 충족한다. 버전 확인만 수행했고 이미지·터널·다른 서비스는 변경하지 않았다. 이 결과를 모든 별도 호스트의 connector 검증으로 확장하지 않는다.
