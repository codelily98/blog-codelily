# 접근성 구현·검증 기준

기준일 2026-11-02. KWCAG 2.2와 적용 기관의 최신 WA 표준심사 지침을 확인한다. WebWatch는 2025-01부터 기술심사에 KWCAG 2.2를 적용한다고 안내한다. [심사 안내·표준 문서](https://www.webwatch.or.kr/contents/view/3), [KWCAG 2.2 자료](https://www.wa.or.kr/board/view.asp?BoardID=0004&sn=22592).

WA 인증 취득은 별도 외부 심사이며 이 저장소의 자동 검사 통과와 동일하지 않다. 심사 전 원문 33개 검사항목을 기준으로 표본 페이지와 모든 핵심 상태를 수동 점검한다. 아래는 구현/검증을 실행하기 위한 작업 묶음이다.

| 작업 | 구현 방침 | 검사 |
|---|---|---|
| 인식 | 한국어 lang·페이지 title·제목 계층·이미지 설명·구조화 목록/표 | DOM/axe + 화면 낭독기 수동 |
| 대비·확대 | 라이트/다크 공통 토큰, 본문 4.5:1·큰 글자/비문자 UI 3:1 기준 확인 | 양 테마 자동 대비 + 200/400% 확대 수동 |
| 키보드·초점 | 모든 제어에 키보드 접근, skip link, focus-visible, dialog 초기 초점·trap·복귀·Escape | 브라우저 키보드 + NVDA/VoiceOver 수동 |
| 입력·오류 | 연결된 label·필수값·오류 안내·상태 알림·서버 검증 | 잘못된 값·중복·권한·실패 상태 |
| 반응형 | 360/390px·가로/세로·텍스트 확대, scroll 영역 구분 | 실제 viewport·문서 가로 넘침 |
| 움직임·시간 | reduced-motion, 깜박임 없음, 상태를 색에만 의존하지 않음 | OS 설정·수동 확인 |
| 인증 | Google 표준 로그인, 비밀번호/인지 퍼즐 자체 구현 없음, 역할 안내 | 실제 Google UI 포함 수동 |
| SunEditor | 명시적 편집 label, 원본 textarea label, 오류·로딩, lifecycle 정리 | HTML/Markdown·toolbar·키보드·낭독기 |
| 차트 | canvas 이름·figure caption·동일 데이터 표·수치 요약 | axe + 표와 차트 값 비교 |
| Grid | Tabulator 이름·상태, native 표 전환·표 caption/열 제목, 최대 row 제한 | 두 모드 자동 검사 + 키보드 탐색 |

사용자가 작성하는 HTML의 색·표·이미지 대체 설명·제목 순서는 게시 콘텐츠 검수 대상이다. sanitize는 XSS 방어이며 자동으로 접근 가능한 콘텐츠를 만들어주는 기능이 아니다. 업로드 UI는 의미 있는 이미지 설명을 요구한다. 자유 HTML 편집으로 만든 대비 불량·빈 링크·레이아웃 표 등은 공개 전에 수정한다.

Google·외부 링크·파일·오류·빈 상태·초안·관리 화면을 포함해 수동 표본을 구성한다. NVDA+Chrome/Edge, VoiceOver+Safari/iOS 등 보조기술과 실제 모바일을 확인한다. 현재 자동 검증이 전체 KWCAG 충족이나 인증 획득을 의미한다고 제품에 표시하지 않는다.

실행 가능한 검사: `tests/e2e/public.spec.ts`, `tests/e2e/management.spec.ts`의 axe 및 동작 검사. 결과와 수동 검사 대기 사항은 `docs/진행현황.md`에 기록한다.
