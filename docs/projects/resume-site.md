# resume-site: 이력서 서비스

상태: 후속 프로젝트. 기능 요구 확정 후 착수한다.

- [ ] 독립 Next.js 앱·resume 스키마·계정·migration
- [ ] Google 로그인·소유권·R2 private 파일
- [ ] 공통 Editor/UI로 섹션별 이력서 작성·순서·미리보기
- [ ] 공개 링크 만료·폐기·검색 노출 정책
- [ ] PDF는 별도 자원 예산/외부 renderer 검토
- [ ] 동의 기반 telemetry·통합 관리자 요약 계약
- [ ] 권한·개인정보·모바일·키보드·백업/복원 검사

code-lily 코드를 복사하지 않는다. 중복된 기술 컴포넌트는 공통 패키지로 옮기고 이력서 domain은 이 앱에 둔다.
