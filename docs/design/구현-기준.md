# 디자인·공통 컴포넌트 기준

code-lily는 기술 글을 중심으로 홈과 아카이브를 구성한다. 홈의 카라꽃 표지는 ImageGen으로 생성해 WebP로 제공한다. [이전 화면 참고 자료](references/README.md)

## 토큰과 레이아웃

- code-lily는 공통 UI 토큰을 사용하고 앱의 배경·표면·본문·보조 글자·강조 색을 재정의한다. 다크 배경은 `#111714`, 본문은 `#f4f3e9`, 강조는 `#c7e7a8`이다. 라이트 배경은 `#f7f8f1`, 본문은 `#19241b`, 강조는 `#34532a`다.
- Pretendard Variable 서브셋을 앱의 정적 자산으로 제공한다. 코드와 날짜는 고정폭 글꼴을 사용한다.
- 공통 헤더는 블로그 홈, Posts, About, 글 검색, 테마, Google 로그인을 제공한다. 세션 권한에 맞춰 Work와 내 Posts를 표시한다. 모바일 헤더에서는 메뉴를 두 번째 줄에 배치한다.
- 헤더·푸터의 카라꽃 로고는 `apps/code-lily/src/app/icon.svg`를 공유한다. Next.js 아이콘 메타데이터는 같은 SVG와 16·24·32·48·64·128·256px 프레임을 포함한 `favicon.ico`를 제공한다.
- 홈은 최대 너비 1480px에서 소개와 표지를 좌우로 두고 최근 글은 날짜·카테고리·제목·요약이 있는 행으로 표시한다. 768px 미만에서는 홈 소개와 표지, 글 행의 날짜와 본문을 세로로 배치한다.
- 글 목록은 검색과 카테고리, 글의 태그 링크, URL 기반 페이지 이동을 제공한다. 공개 글 상세는 최대 800px 안에 본문을 배치한다. 본문 소제목이 하나 이상이면 키보드로 이동할 수 있는 목차를 제공한다.
- About은 좁은 본문, 경력/기간 행, 관심사 목록, 연락처 링크를 사용한다. 버튼과 주요 링크는 최소 높이 44px을 적용하며 공통 초점 스타일과 동작 줄이기 설정을 따른다.

## 작성 화면

- 게시글은 상단에 저장 상태와 작업 버튼, 본문 오른쪽에 게시 설정을 둔다. 모바일에서는 본문 아래에 게시 설정을 표시한다.
- Work와 게시글은 배경·글자 대비가 같은 편집 영역과 44px Markdown 도구를 공유한다. Work의 문서 관리 버튼은 본문 아래에 두고, 편집·미리보기의 현재 상태를 표시한다.

## 확인 항목

1. 홈 소개, 헤더 메뉴, RSS 링크와 첫 글 목록이 화면에서 읽히는가.
2. 카라꽃 이미지 구도와 프레임이 데스크톱과 모바일에서 유지되는가.
3. 양 테마에서 헤더 메뉴, 글 제목·요약·태그와 검색 필드의 대비가 확보되는가.
4. 390px에서 가로 넘침 없이 카테고리를 탐색하고 목차 링크로 이동할 수 있는가.
5. 검색·카테고리·태그·페이지 이동과 칼럼 변화가 표시된 상태와 일치하는가.
6. 글 비공개 전환 후 홈·아카이브·상세·RSS가 최신 공개 상태를 사용하고 편집 원문이 외부에 노출되지 않는가.
